# Saksham Khetan — Portfolio

A personal portfolio built with HTML and CSS, featuring projects, experience, education, skills, and interests.

## View the website

https://saksh1m.github.io/saksham-portfolio/

## Files

- `index.html` — page content and navigation
- `style.css` — styling, responsive layouts, and CSS illustrations
- `saksham.jpeg` — profile photograph
- `favicon.svg` — site icon
- `.nojekyll` — static publishing configuration

Open `index.html` in a browser to preview locally. No dependencies or build step are needed.

## Design

Dark colours, violet accents, and orbital artwork inspired by [ladunjexa’s 3D portfolio](https://github.com/ladunjexa/reactjs18-3d-portfolio). The HTML, CSS illustrations, and favicon are original. The page includes keyboard navigation, image descriptions, and reduced-motion support.

## Hosting

Published with GitHub Pages from the `main` branch and repository root.
